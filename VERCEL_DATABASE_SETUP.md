# 🗄️ Vercel Database Setup Guide

Your app is deployed but needs a database. Follow these steps to set up Vercel Postgres.

## 🚀 Quick Setup (5 minutes)

### Step 1: Create Vercel Postgres Database

1. **Go to your Vercel project dashboard**
   - Visit: https://vercel.com/dashboard
   - Select your project: `mountplus-sales-and-expenses-tracker`

2. **Navigate to Storage tab**
   - Click **"Storage"** in the top menu
   - Click **"Create Database"**

3. **Select Postgres**
   - Choose **"Postgres"**
   - Click **"Continue"**

4. **Configure Database**
   - **Database Name**: `mountplus-db` (or any name)
   - **Region**: Choose closest to your users
   - Click **"Create"**

5. **Connect to Project**
   - Select your project from the list
   - Click **"Connect"**
   - Vercel will automatically add environment variables

### Step 2: Verify Environment Variables

1. **Go to Project Settings**
   - Click **"Settings"** tab
   - Click **"Environment Variables"**

2. **Check these variables exist:**
   - `POSTGRES_URL`
   - `POSTGRES_PRISMA_URL`
   - `POSTGRES_URL_NON_POOLING`
   - `POSTGRES_USER`
   - `POSTGRES_HOST`
   - `POSTGRES_PASSWORD`
   - `POSTGRES_DATABASE`

3. **Add DATABASE_URL** (if not auto-added)
   - Click **"Add New"**
   - **Key**: `DATABASE_URL`
   - **Value**: Copy from `POSTGRES_PRISMA_URL`
   - **Environments**: Production, Preview, Development
   - Click **"Save"**

### Step 3: Run Database Migrations

You have two options:

#### Option A: Using Vercel CLI (Recommended)

```bash
# Install Vercel CLI if not installed
npm i -g vercel

# Login to Vercel
vercel login

# Link to your project
vercel link

# Pull environment variables
vercel env pull .env.local

# Generate Prisma Client
npx prisma generate

# Push database schema
npx prisma db push

# (Optional) Seed with sample data
# npx prisma db seed
```

#### Option B: Using Vercel Dashboard

1. **Go to your project**
2. **Click "Deployments"**
3. **Click on the latest deployment**
4. **Click "..." menu → "Redeploy"**
5. **Check "Use existing Build Cache"**
6. **Click "Redeploy"**

The build will automatically run `prisma generate` and create tables.

### Step 4: Initialize Database Tables

After deployment, you need to create the tables:

```bash
# Using Vercel CLI with pulled env vars
npx prisma db push
```

Or manually run SQL in Vercel Postgres dashboard:

1. Go to **Storage** → Your database
2. Click **"Query"** tab
3. Run this SQL:

```sql
-- This will be auto-generated by Prisma
-- Just run: npx prisma db push
```

### Step 5: Redeploy

1. **Trigger new deployment**
   - Go to **Deployments**
   - Click **"Redeploy"**
   - OR push a new commit to GitHub

2. **Wait for deployment**
   - Should complete successfully now
   - Check deployment logs for any errors

3. **Test your app**
   - Visit your Vercel URL
   - Try creating a quote
   - Add a sale
   - Record an expense

## 🔄 Alternative: Use Neon (Free PostgreSQL)

If you prefer a free external database:

### 1. Create Neon Account
- Visit: https://neon.tech
- Sign up (free tier available)
- Create a new project

### 2. Get Connection String
- Copy the connection string
- Format: `postgresql://user:password@host/database?sslmode=require`

### 3. Add to Vercel
- Go to Vercel → Settings → Environment Variables
- Add `DATABASE_URL` with Neon connection string
- Redeploy

### 4. Run Migrations
```bash
# Set DATABASE_URL locally
export DATABASE_URL="your-neon-connection-string"

# Push schema
npx prisma db push
```

## 🔄 Alternative: Use Supabase (Free PostgreSQL)

### 1. Create Supabase Project
- Visit: https://supabase.com
- Create new project
- Wait for database to provision

### 2. Get Connection String
- Go to **Settings** → **Database**
- Copy **Connection string** (Transaction mode)
- Replace `[YOUR-PASSWORD]` with your password

### 3. Add to Vercel
- Add `DATABASE_URL` in Vercel environment variables
- Format: `postgresql://postgres:[PASSWORD]@[HOST]:5432/postgres`

### 4. Run Migrations
```bash
npx prisma db push
```

## 🆘 Troubleshooting

### Error: "Can't reach database server"

**Solution**: Check DATABASE_URL format
```bash
# Should look like:
postgresql://user:password@host:5432/database?schema=public
```

### Error: "Prisma Client not generated"

**Solution**: Regenerate and redeploy
```bash
npx prisma generate
git add .
git commit -m "Regenerate Prisma Client"
git push
```

### Error: "Table doesn't exist"

**Solution**: Run migrations
```bash
# Pull Vercel env vars
vercel env pull .env.local

# Push schema
npx prisma db push
```

### Error: "SSL connection required"

**Solution**: Add SSL to connection string
```
?sslmode=require
```

## 📊 Database Management

### View Data
- **Vercel Postgres**: Use built-in query editor
- **Neon**: Use Neon dashboard
- **Supabase**: Use Table Editor

### Backup Data
```bash
# Export data
npx prisma db pull

# Or use pg_dump
pg_dump $DATABASE_URL > backup.sql
```

### Reset Database
```bash
# ⚠️ WARNING: This deletes all data
npx prisma migrate reset
```
